# Production Go-Live Deployment Guide

FinLedger supports two production deployment topologies:
1. **Split Cloud (Recommended)**: **Render** (Express + Socket.IO API) + **Vercel** (React SPA) + **MongoDB Atlas**.
2. **Single-Container Docker**: Build and run [Dockerfile](file:///d:/BCA/SEM-6/FinLedger/Dockerfile) on Railway, Fly.io, Cloud Run, or any VPS (`SERVE_CLIENT=true`).

---

## Option A: Split Cloud (MongoDB Atlas + Render + Vercel)

### 1. MongoDB Atlas Setup
1. Create a MongoDB Atlas cluster (Replica Set — M0 free tier or dedicated supports multi-document ACID transactions).
2. Create a database user and add Network Access (or Render outbound IPs / `0.0.0.0/0` with strong credentials).
3. Copy your connection string (`MONGO_URI`):
   `mongodb+srv://<user>:<password>@<cluster>.mongodb.net/finledger?retryWrites=true&w=majority`

### 2. Backend API on Render (`render.yaml`)
1. Connect your repository to Render using the included [render.yaml](file:///d:/BCA/SEM-6/FinLedger/render.yaml) blueprint (`rootDir: server`, `healthCheckPath: /api/v1/health`).
2. Set the required environment variables (reference [server/.env.production.example](file:///d:/BCA/SEM-6/FinLedger/server/.env.production.example)):
   - `NODE_ENV=production`
   - `USE_MEMORY_DB=false`
   - `MONGO_URI=<your-atlas-connection-string>`
   - `JWT_ACCESS_SECRET` & `JWT_REFRESH_SECRET` (auto-generated by `render.yaml`, or >= 32 chars each)
   - `CLIENT_URL=https://<your-vercel-domain>.vercel.app` (no trailing slash)
   - `CORS_ORIGIN=https://<your-vercel-domain>.vercel.app`
3. Optional integrations:
   - **SMTP Email**: `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`
   - **Persistent Receipts**: Attach a Render Disk (e.g., `/var/data/uploads`) and set `RECEIPTS_DIR=/var/data/uploads` so uploaded receipts survive redeploys.

### 3. Frontend SPA on Vercel (`vercel.json`)
1. Import the repository into Vercel (uses [vercel.json](file:///d:/BCA/SEM-6/FinLedger/vercel.json) with security headers and SPA fallback rewrites).
2. Set Environment Variables in Vercel (reference [client/.env.example](file:///d:/BCA/SEM-6/FinLedger/client/.env.example)):
   - `VITE_API_URL=https://<your-render-api>.onrender.com/api/v1`
   - `VITE_SOCKET_URL=https://<your-render-api>.onrender.com`
3. Deploy and copy your final `https://<your-vercel-domain>.vercel.app` URL back into Render's `CLIENT_URL` and `CORS_ORIGIN`.

## Option B: Single-Container Docker (`Dockerfile`)

```bash
docker build -t finledger .
docker run -p 5000:5000 \
  -e MONGO_URI="mongodb+srv://..." \
  -e JWT_ACCESS_SECRET="..." \
  -e JWT_REFRESH_SECRET="..." \
  -e CLIENT_URL="https://finledger.example.com" \
  -e CORS_ORIGIN="https://finledger.example.com" \
  -v finledger_uploads:/app/server/uploads \
  finledger
```

## Pre-Launch Verification Check

Before deploying, run:
```bash
npm run lint && npm run build && npm run check:prod && npm test && npm run test:e2e
```
